Wypożyczalnia Samochodów

Autorzy

  • Kamil Grabiec

Opis systemu

System ma na celu usprawnienie procesu zarządzania flotą oraz ewidencji wypożyczeń w lokalnej wypożyczalni samochodów, eliminując błędy wynikające z ręcznego prowadzenia dokumentacji.

Głównymi użytkownikami są pracownicy biurowi (obsługa klienta) oraz administrator (zarządzanie flotą i cennikiem).

System umożliwia pracownikom rejestrowanie klientów, przeglądanie i zarządzanie flotą pojazdów, tworzenie umów wypożyczenia, rejestrowanie zwrotów oraz automatyczne obliczanie kosztów wynajmu na podstawie zdefiniowanych stawek dziennych, weekendowych i tygodniowych.

Administratorzy mają dostęp do rozszerzonych funkcji, takich jak generowanie raportów (miesięcznych, floty, przychodów), zarządzanie kontami użytkowników systemu oraz konfiguracja połączenia z bazą danych.

System zapewnia automatyczną walidację danych, kontrolę dostępności pojazdów w czasie rzeczywistym oraz mechanizm blokady kont po wielokrotnych nieudanych próbach logowania.

Aplikacja desktopowa została zrealizowana w technologii C# (.NET 8) z wykorzystaniem Avalonia UI, wzorca MVVM (ReactiveUI) oraz relacyjnej bazy danych MariaDB ( MySqlConnector).

System description

The system aims to streamline fleet management and rental record-keeping at a local car rental company, eliminating errors caused by manual documentation.

The primary users are office employees (customer service) and administrators (fleet and pricing management).

The system enables employees to register customers, browse and manage the vehicle fleet, create rental agreements, process vehicle returns, and automatically calculate rental costs based on defined daily, weekend, and weekly rates.

Administrators have access to extended features such as report generation (monthly, fleet utilization, revenue), user account management, and database connection configuration.

The system provides automatic data validation, real-time vehicle availability checking, and an account lockout mechanism after multiple failed login attempts.

The desktop application is built using C# (.NET 8) with Avalonia UI, MVVM pattern (ReactiveUI), and MariaDB relational database (MySqlConnector).

Słownik pojęć

  • System zarządzania flotą Wewnętrzna aplikacja desktopowa umożliwiająca pracownikom wypożyczalni zarządzanie flotą pojazdów, ewidencją wypożyczeń oraz bazą klientów.
  • Klient Osoba fizyczna lub prawna korzystająca z usług wypożyczalni samochodów. Klient nie posiada konta w systemie — jest obsługiwany przez pracownika biurowego.
  • Pojazd Samochód należący do floty wypożyczalni, przypisany do kategorii cennikowej. Każdy pojazd posiada unikalne cechy: marka, model, numer rejestracyjny, VIN, status dostępności.
  • Kategoria pojazdu Klasyfikacja pojazdów (np. Ekonomiczny, Kompaktowy, SUV, Premium) definiująca stawki cennikowe: dzienną, weekendową, tygodniową, kaucję oraz limit kilometrów.
  • Wypożyczenie (Rental) Umowa wynajmu pojazdu klientowi na określony czas. Zawiera dane klienta, pojazdu, pracownika obsługującego, daty, przebieg, kalkulację kosztów i status płatności.
  • Zwrot pojazdu Proces zakończenia wypożyczenia: rejestracja przebiegu końcowego, ocena stanu pojazdu, naliczenie ewentualnych dopłat (nadprogramowe km, spóźnienie, uszkodzenia) i rozliczenie kaucji.
  • Pracownik Użytkownik systemu z rolą „employee", odpowiedzialny za obsługę klientów, zarządzanie pojazdami i ewidencję wypożyczeń.
  • Administrator Użytkownik systemu z rolą „admin", posiadający uprawnienia pracownika plus dostęp do raportów, zarządzania kontami użytkowników i konfiguracji systemu.
  • Flota pojazdów Zbiór wszystkich samochodów zarejestrowanych w systemie, podzielonych na kategorie cennikowe.
  • Dostępność pojazdu Status pojazdu określający możliwość jego wypożyczenia: dostępny, wypożyczony, w serwisie, wycofany.
  • Kaucja Kwota wpłacana przez klienta przy wypożyczeniu jako zabezpieczenie. Zwracana przy zwrocie pojazdu po potrąceniu ewentualnych kosztów uszkodzeń.
  • Numer umowy Automatycznie generowany identyfikator wypożyczenia w formacie WYP-RRRR-NNNNNN.

Dictionary

  • Fleet Management System Internal desktop application enabling rental company employees to manage the vehicle fleet, rental records, and customer database.
  • Customer Natural or legal person using car rental services. Customers do not have system accounts — they are served by office employees.
  • Vehicle Car belonging to the rental fleet, assigned to a pricing category. Each vehicle has unique characteristics: brand, model, registration number, VIN, availability status.
  • Vehicle Category Vehicle classification (e.g., Economy, Compact, SUV, Premium) defining pricing rates: daily, weekend, weekly, deposit amount, and mileage limit.
  • Rental Vehicle rental agreement with a customer for a specified period. Contains customer data, vehicle, servicing employee, dates, mileage, cost calculation, and payment status.
  • Vehicle Return Process of completing a rental: recording final mileage, assessing vehicle condition, calculating additional charges (excess km, late return, damages) and settling the deposit.
  • Employee System user with "employee" role, responsible for customer service, vehicle management, and rental record-keeping.
  • Administrator System user with "admin" role, having all employee permissions plus access to reports, user account management, and system configuration.
  • Vehicle Fleet Complete collection of cars registered in the system, divided into pricing categories.
  • Vehicle Availability Vehicle status indicating rental possibility: available, rented, in service, withdrawn.
  • Deposit Amount paid by the customer at rental start as security. Returned upon vehicle return after deducting any damage costs.
  • Rental Number Automatically generated rental identifier in format WYP-YYYY-NNNNNN.

User Stories (po polsku)

Jako pracownik chcę zalogować się do systemu, aby uzyskać dostęp do funkcji obsługi klientów i zarządzania flotą.

Jako pracownik chcę przeglądać dostępne samochody z filtrowaniem po statusie i kategorii, aby szybko znaleźć odpowiedni pojazd dla klienta.

Jako pracownik chcę wyszukiwać klientów po nazwisku, telefonie lub PESEL, aby sprawnie obsłużyć powracającego klienta.

Jako pracownik chcę zarejestrować nowego klienta w systemie, aby umożliwić mu skorzystanie z usług wypożyczalni.

Jako pracownik chcę edytować dane klienta, aby utrzymywać aktualne informacje kontaktowe w systemie.

Jako pracownik chcę utworzyć nowe wypożyczenie wybierając klienta, pojazd i daty, aby system automatycznie obliczył koszt i wygenerował umowę.

Jako pracownik chcę, aby system automatycznie sprawdzał dostępność pojazdu w wybranym terminie, aby uniknąć konfliktów rezerwacji.

Jako pracownik chcę zarejestrować zwrot pojazdu wpisując przebieg końcowy i ewentualne uszkodzenia, aby system rozliczył klienta i zwolnił samochód.

Jako pracownik chcę anulować aktywne wypożyczenie, aby obsłużyć sytuację gdy klient rezygnuje przed odbiorem pojazdu.

Jako pracownik chcę przeglądać listę aktywnych wypożyczeń z oznaczeniem przeterminowanych, aby monitorować stan bieżących umów.

Jako pracownik chcę dodać nowy pojazd do floty podając markę, model, rejestrację, VIN i kategorię cennikową, aby zwiększyć dostępność samochodów.

Jako pracownik chcę edytować informacje o pojeździe i oznaczyć go jako „w serwisie", aby klienci nie mogli go wypożyczyć podczas naprawy.

Jako pracownik chcę widzieć na pulpicie statystyki: liczbę dostępnych aut, aktywnych umów, przychód i alerty, aby mieć szybki przegląd sytuacji.

Jako administrator chcę generować raport miesięczny z podsumowaniem wypożyczeń i przychodów, aby analizować wyniki finansowe.

Jako administrator chcę generować raport wykorzystania floty, aby identyfikować pojazdy o niskim obłożeniu.

Jako administrator chcę generować raport przychodów z podziałem na metody płatności i zaległości, aby kontrolować przepływy finansowe.

Jako administrator chcę zarządzać kontami pracowników (tworzenie, dezaktywacja), aby kontrolować dostęp do systemu.

Jako administrator chcę konfigurować połączenie z bazą danych MariaDB z poziomu ustawień aplikacji, aby nie wymagać zmian w kodzie przy migracji serwera.

User Stories (in english)

As an employee I want to log into the system so that I can access customer service and fleet management functions.

As an employee I want to browse available cars with status and category filters so that I can quickly find a suitable vehicle for a customer.

As an employee I want to search for customers by surname, phone number, or PESEL so that I can efficiently serve returning customers.

As an employee I want to register a new customer in the system so that they can use the rental services.

As an employee I want to edit customer data so that I can keep contact information up to date in the system.

As an employee I want to create a new rental by selecting customer, vehicle, and dates so that the system automatically calculates costs and generates the agreement.

As an employee I want the system to automatically check vehicle availability for the selected dates so that reservation conflicts are avoided.

As an employee I want to register a vehicle return by entering final mileage and any damages so that the system settles the customer and releases the car.

As an employee I want to cancel an active rental so that I can handle situations when a customer withdraws before vehicle pickup.

As an employee I want to view the list of active rentals with overdue indicators so that I can monitor current agreements.

As an employee I want to add a new vehicle to the fleet by providing brand, model, registration, VIN, and pricing category so that car availability increases.

As an employee I want to edit vehicle information and mark it as "in service" so that customers cannot rent it during maintenance.

As an employee I want to see dashboard statistics including available cars, active agreements, revenue, and alerts so that I have a quick overview of the business.

As an administrator I want to generate a monthly report summarizing rentals and revenue so that I can analyze financial results.

As an administrator I want to generate a fleet utilization report so that I can identify underperforming vehicles.

As an administrator I want to generate a revenue report broken down by payment method and outstanding amounts so that I can control cash flows.

As an administrator I want to manage employee accounts (create, deactivate) so that I can control system access.

As an administrator I want to configure the MariaDB connection from the application settings so that server migration does not require code changes.
